# Toolkit (Kopie für schnellen Start)

`bash toolkit/setup.sh <slug>` legt `~/mw/` mit Roboter, Logo, Fonts und allen Skripten an.
Vorlage ist `build_fz.py` (Führungszeugnis, 10 Beats; liest Wortzeiten aus `ws.json`) und `thumb_fz.py`.
Ausführliche Doku (Element-Attribute, Sounddesign, Mux-Befehl) steht im claude.ai-Projekt unter toolkit/README.md.
